# /stage — одна сессия карточки

Аргументы владельца: $ARGUMENTS

**Вспомнить, где мы, — не больше 3 ходов и ~20k токенов.**
1. «Следующий шаг» и «Проверить глазами» уже подставлены хуком — `STATUS.md` не читай.
2. Прочитай `.private/HANDOFF.md` (короткий) и **только** карточку `.private/cards/<id>.md` (id — первое слово аргументов; нет id — карточка из HANDOFF «Текущая карточка»). Из карточки делай только текущую сессию.
3. Не читай целиком: `STATUS_LOG.md`, `archive/`, `DECISIONS.md`, `story/*`, `docs/LESSONS.md`, `docs/BUG_LOG.md`, `docs/TEST_PLAN.md`, Lua-файлы > 300 строк. Только `grep -n` и диапазоны строк, которые нужны пункту. Файлы, которые назвала карточка, — можно.
4. Не перепроверяй сделанное: `git log -5 --oneline` и «Результат» в HANDOFF — достаточно. Не перечитывай файл, который уже в контексте.
5. Остаток аргументов — результат проверки Влада: одной строкой в `STATUS.md` «## В работе», баги — `log_bug_report`. Мелкие баги чинить в этой же сессии.
6. Делай пункты по порядку. Перед каждым следующим пунктом посмотри на размер контекста: > 150k — новый пункт не начинать, сразу `/wrap`.
7. В конце — `/wrap`. Следующую сессию карточки не начинай.
